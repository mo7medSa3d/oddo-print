## DESK-001

- **ID:** DESK-001
- **Severity:** P1
- **Subsystem:** Desktop / Tauri authorization
- **File/location:** `src-tauri/capabilities/default.json`; `src-tauri/src/main.rs`; `src/desktop/lib/ipc.ts`
- **Problem:** The UI invokes `relaunch_as_admin` and Rust registers the command, but the `main` window capability did not grant `allow-relaunch-as-admin`.
- **Root cause:** IPC registration and the Tauri 2 capability allowlist drifted apart.
- **Affected flows:** Administrator relaunch from the desktop privilege dialog; privileged Agent service installation/repair/start recovery.
- **Fix strategy:** Add the exact generated command permission to the existing main-window capability without broadening unrelated privileges.
- **Status:** FIXED — PR build/runtime verification pending.
